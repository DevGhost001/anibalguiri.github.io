Introduction to Cybersecurity

{ Minha História

Olá! Sou Aníbal Guiri, estudante do curso técnico de informática em Luanda, Angola. Desde cedo fiquei fascinado pela forma como os computadores funcionam — e mais ainda pelo que acontece quando as coisas não deveriam funcionar.

A minha introdução à programação começou com páginas web em HTML e CSS. Rapidamente expandi para JavaScript, depois para C, C# e Python. Cada linguagem me abriu uma nova porta de conhecimento.

{ Porquê Cybersegurança?

A virada aconteceu quando descobri o mundo do ethical hacking. Percebi que proteger sistemas requer conhecê-los profundamente — inclusive saber como quebrá-los. Completei o curso Introduction to Cybersecurity da Cisco Networking Academy e desde então não parei mais.

O meu objetivo é tornar-me um profissional de cibersegurança de referência em África, contribuindo para um ecossistema digital mais seguro.
